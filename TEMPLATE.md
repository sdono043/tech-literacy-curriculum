# Module Template (TLC blueprint)

Copy everything below the line into `modules/NN-short-topic.md` and fill it in. Keep the
section order — it's the shape every TLC module shares, and learners come to rely on it.

Guiding principles:
- **Source it from something real.** Every module names the live session / project it came
  from (see the last section). If you can't name a real moment it teaches, it isn't a TLC module yet.
- **Objectives are verbs.** "Explain…", "Identify…", "Configure…", "Diagnose…" — things a
  learner can *do*, not topics they've "covered."
- **Labs over lectures.** The Core Concepts exist to make the Labs doable. The Labs are the module.
- **Teach the gotcha.** The most valuable paragraph in each module is usually the one about the
  thing that *didn't* just work — the wildcard record, the frozen function, the stale cache.
